## Why vRT

<CardGrid>
  <Card title="Protocol-first" icon="document">
    A language-neutral specification with JSON Schemas and test vectors defines what "compatible" means. The TypeScript packages are its reference implementation, not its definition.
  </Card>
  <Card title="Interruptible by design" icon="warning">
    Every turn has an epoch. Once the user interrupts, nothing from that turn takes effect: its tool calls never start and its audio never plays.
  </Card>
  <Card title="Tools run where they belong" icon="laptop">
    Server tools run next to the agent; app tools run in the user's page or device, one at a time, behind the epoch gate.
  </Card>
  <Card title="Any model" icon="random">
    Boson Higgs Realtime, OpenAI Realtime, Gemini Live, or any text LLM with speech-to-text and text-to-speech. Switching models changes no app code.
  </Card>
  <Card title="Runs anywhere" icon="rocket">
    Node, Bun, Deno, Cloudflare Workers and Durable Objects, and the browser. Web-standard APIs only; no media server.
  </Card>
  <Card title="Light" icon="star">
    A zero-dependency core, one small package per provider, binary audio frames instead of base64 JSON, and size budgets enforced in CI.
  </Card>
</CardGrid>
