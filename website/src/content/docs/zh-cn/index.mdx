## 为什么选 vRT

<CardGrid>
  <Card title="协议优先" icon="document">
    与语言无关的协议规范，配 JSON Schema 和测试用例，定义什么叫"兼容"。TypeScript 包是参考实现，不是定义本身。
  </Card>
  <Card title="生来可打断" icon="warning">
    每一轮都有一个 epoch。用户一打断，这一轮的东西都不再生效：工具调用不会开始，音频不会播放。
  </Card>
  <Card title="工具在该在的地方执行" icon="laptop">
    服务端工具跑在 agent 旁边；App 工具跑在用户的网页或设备里，按顺序逐个执行，并受 epoch 闸门约束。
  </Card>
  <Card title="任何模型" icon="random">
    Boson Higgs Realtime、OpenAI Realtime、Gemini Live，或者任何文本大模型加上语音识别和语音合成。换模型不用改 App 代码。
  </Card>
  <Card title="到处能跑" icon="rocket">
    Node、Bun、Deno、Cloudflare Workers 和 Durable Objects，以及浏览器。只用 Web 标准 API，不需要媒体服务器。
  </Card>
  <Card title="轻" icon="star">
    零依赖的核心，每家模型一个小包，音频走二进制帧而不是 base64 JSON，体积预算由 CI 强制检查。
  </Card>
</CardGrid>
